#Webサーバー2本

  • 脆弱性2026年11月21日

    NGINX に複数の脆弱性、HTTP/2 を使う構成で遠隔からコード実行のおそれ

    Webサーバー・リバースプロキシとして広く使われる NGINX に、CVSS v4.0 で 9.2 の脆弱性5件を含む複数の脆弱性。11月18日に修正版 1.30.7 / 1.31.9 が公開され、IPA が対策を呼びかけている。

    視点NGINX は自社で入れた覚えがなくても、ロードバランサー、Kubernetes の入口、アプライアンスの中に入っていることが多い。OS のパッケージは版番号を変えずに修正を取り込む場合もあり、「バージョン番号の一覧表」だけで影響を判断する運用はここで破綻する。

    1週間以内に対応

  • 脆弱性2026年11月21日

    PHP に任意のコード実行につながる複数の脆弱性、11月19日に修正版を公開

    The PHP Group が深刻度 Critical の7件を含む脆弱性を修正した PHP 8.5.13 / 8.4.28 / 8.3.37 / 8.2.36 を公開。IPA と JPCERT/CC が更新を呼びかけている。新たな脆弱性の悪用は現時点で確認されていない。

    視点10月の「PHP2shell」では、PHP を組み込んだファイアウォール製品が侵害され、社内への足場にされたことを示唆する痕跡が報告された。自社の Web サイトだけでなく、管理画面に PHP を使うネットワーク機器や業務パッケージも対象になる。「うちは PHP を使っていない」と言い切れる組織は、実は少ない。

    1週間以内に対応
